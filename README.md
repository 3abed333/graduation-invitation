# دعوة عشاء التخرّج 🎓

كرت دعوة لعشاء التخرّج بالكحلي والذهبي.

**الرابط:** https://3abed333.github.io/graduation-invitation/

## التعديل

كل النصوص موجودة في `index.html`، والأماكن اللي بتنعدّل عليها علامة ✏️:

- اسم المعزوم
- اليوم والتاريخ، الساعة، المكان (ورابط الخريطة)، اللباس
- عدد الأشخاص

بعد أي تعديل اعمل commit و push، والرابط بيتحدّث لحاله خلال دقيقة أو دقيقتين.
