## التعديل

كل كرت إله ملف `index.html` خاص فيه (الأول بالمجلد الرئيسي، والثاني بمجلد `khadija/`)، والأماكن اللي بتنعدّل عليها علامة ✏️:

- اسم المعزوم واسم الخرّيج
- اليوم والتاريخ، الساعة، المكان (ورابط الخريطة)، اللباس
- عدد الأشخاص

إذا عدّلت إشي مشترك (التاريخ، المكان، اللباس...) عدّله بالملفين.

بعد أي تعديل اعمل commit و push، والرابط بيتحدّث لحاله خلال دقيقة أو دقيقتين.
